# Contributing

Thank you for improving Slate. Keep changes focused, preserve deterministic offline behavior, and avoid committing credentials, local data, generated databases, or provider caches.

1. Create a focused branch from `main`.
2. Update tests and documentation with behavior changes.
3. Run the checks listed in the README.
4. Open a pull request using the template and describe any data-source, licensing, or financial-risk implications.

Do not add live provider calls to tests. Use the deterministic sample provider and redact sensitive information from logs, screenshots, and issue reports.
